# Atlassian — Jira/Confluence Integration

Source: https://www.claudepluginhub.com/plugins/777genius-atlassian-plugins-atlassian

Claude Code plugin for interacting with Jira and Confluence.

## Env vars

- `ATLASSIAN_BASE_URL` — your Atlassian instance URL

## Not in default install

This component is optional. Install manually:

```bash
ai-install services atlassian
```
