# Draw.io Diagramming — Diagram Generation

Source: https://www.claudepluginhub.com/plugins/markus41-drawio-diagramming-plugins-drawio-diagramming

Claude Code plugin that generates `.drawio` diagrams (architecture, flow, sequence, etc.) directly from conversation.

## Usage

Ask Claude Code to create a diagram and it will output a `.drawio` file you can open in draw.io or VS Code with the draw.io extension.

## Not in default install

This component is optional. Install manually:

```bash
ai-stack-install services drawio
```
